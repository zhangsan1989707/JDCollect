# 飞书同步快速配置

## 方式一：使用预设模板（推荐）

1. 点击链接导入模板：https://bytedance.feishu.cn/share/base/form/shrcnK4v4Z0J6K1L1M2N3O4P5Q6R
2. 保存到自己的飞书空间
3. 点击右上角"…" → "更多" → "添加应用"
4. 添加你的自建应用为协作者（可编辑权限）
5. 复制表格链接中的 Token 填入插件

## 表格字段说明

预设模板包含以下字段：
- 职位名称
- 公司名称
- 薪资
- 地点
- 经验要求
- 学历要求
- 标签
- 职位链接
- 来源平台
- 采集时间
- 投递状态
- 备注
